# Marble Roulette

물리 엔진(Box2D) 기반 구슬 추첨기입니다.

이 프로젝트는 [lazygyu/roulette](https://github.com/lazygyu/roulette)를 기반으로 광고 요소를 제거하고 Vite로 번들링 환경을 리메이크한 버전입니다.

## 기술 스택

- TypeScript
- Vite
- SCSS
- box2d-wasm

## 실행 및 빌드

### 의존성 설치
```bash
npm install
```

### 개발 서버 실행
```bash
npm run dev
```

### 프로덕션 빌드
```bash
npm run build
```
